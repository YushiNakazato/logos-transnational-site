OUR WORKS

コードを整える手間を、開発する時間へ。

React Redux Manager

定型的なコードの作成と整理を、もっと扱いやすく。React・Reduxの開発を補助する管理ツールを開発しました。

関連するコードを、まとめて扱う

情報や操作に関わるReduxの単位と、画面を構成するReactコンポーネントを整理。モジュールやフォルダーの作成・変更に伴う作業を支援しました。

探す、開く、コピーする手間を減らす

既定のエディターでファイルを開く機能、importやdispatchのコードをコピーする機能を用意。ページと部品を分けて管理し、StyledComponentCreatorではコードとCSSを見つけやすくしました。
